# 抖音 CPS 五期航海情报站

这是给 Cloudflare Pages 部署用的独立目录，避免误用 `项目/航海运营工作台`。

## Cloudflare Pages 设置

- Repository：`heweimian-sys/Work-AI`
- Root directory：`项目/抖音CPS航海情报站`
- Build command：`npm run build`
- Build output directory：`dist`

## 内容边界

- 内容来源：生财 MCP 群聊记录提炼。
- 不展示微信群原文。
- 不包含微信解密、微信导入、本地聊天记录读取。
- 不展示船员名册。
- 每日内容应先人工审核，再更新到页面。
