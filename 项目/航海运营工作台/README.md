# 抖音 CPS 五期航海情报站

面向抖音 CPS（5期）9 月 Mini 航海船员的公开阅读网站。网站把生财 MCP 可读取的四个航海群消息整理成每日情报，帮助没有时间翻群的船员快速看到当天主线、关键答疑、工具入口、实操经验和内容战报。

线上站点沿用原 `航海运营工作台` 的 Cloudflare 绑定，由 GitHub main 分支更新后自动构建发布。

## 当前页面

- 今日概览：展示当天航行状态、核心变化、关键时间线和数据覆盖。
- 每日情报：按当天真实群聊内容生成章节，支持最新情报和 Day 0—Day 4 往期情报。
- 分享长文：每一期日报可一键复制完整长文，往期情报也使用同一套分享结构。

## 数据来源

当前公开版只使用生财 MCP 拉取的群聊消息，经人工审核后写入 `content/site-data.ts`。网站不读取微信本地数据库，不接入微信解密接口，不公开群聊原文、消息 ID、用户 ID、头像或联系方式。

## 内容原则

- 先高召回：事实、问题、有效回答、失败过程、实操方法、结果样本都进入候选。
- 再人工审核：未核验推断不写成公开结论。
- 不展示无行动价值消息：收到、表情、寒暄、拍一拍、重复转述不进入公开页。
- 不压缩成 AI 摘要：保留场景、条件、边界和下一步动作，让船员读完能行动。
